# Contribuir

1. Crear una rama feature/, fix/, chore/ o docs/.
2. Para reglas nuevas, escribir pruebas antes de implementar (TDD).
3. Mantener cambios pequeños y enfocados.
4. Ejecutar compilación Release x64 y pruebas.
5. Abrir Pull Request hacia main y esperar CI verde.

Usar Conventional Commits: feat, fix, test, docs, refactor, build o chore.
Ejemplo: feat(core): define merge operation contract.

Revisar separación de responsabilidades, compatibilidad x64, manejo de errores, privacidad, licencias y documentación.
